# Oorspronkelijke gebruikersprompt

Onderstaande prompt is ongewijzigd opgenomen, zoals gevraagd.

> Voor het aansturen van OBS Websocket dmv de app Chataigne gebruik ik een plugin. Zowel de OBS Websocket Chataigne module als de OBS Websocket Advanced geven foutmeldingen omdat ze (bijv) voor de SetSourceProjector opdracht lege waarden sturen die OBS niet accepteert. Ook werkt GetMonitorList niet naar behoren. 
>
> Voordat je verder gaat; loop [https://github.com/Edrig/OBS-Websocket-Chataigne-Module/forks](https://github.com/Edrig/OBS-Websocket-Chataigne-Module/forks) en[https://github.com/KopiasCsaba/Chataigne-Module-OBS-Websocket-Advanced/forks](https://github.com/KopiasCsaba/Chataigne-Module-OBS-Websocket-Advanced/forks) na en kijk of iemand anders met een fork al een fix gemaakt heeft.
>
> Zo niet, dan wil ik bij voorkeur de Advanced variant herschreven hebben. 
>
> Loop daarbij de complete OBS [https://github.com/obsproject/obs-websocket/blob/master/docs/generated/protocol.md](https://github.com/obsproject/obs-websocket/blob/master/docs/generated/protocol.md) websocket setup na en vergelijk met de implementatie in de plugin. 
>
> Honoreer uiteraard de programmeer eisen van de Chataigne Modules: [https://benkuper.notion.site/Making-your-own-Module-f892f4150bc74dc1b851ba1a3c99510d](https://benkuper.notion.site/Making-your-own-Module-f892f4150bc74dc1b851ba1a3c99510d)
>
> Biedt mij een compleet nagelopen vernieuwde Module: OBS Chataigne Advanced 2026
>
> Test de werking met de openstaande Chataigne en OBS instance. Die mag je bedienen. 
>
> Als je klaar bent documenteer je alles in een nieuwe GitHub commit (mijn GitHub staat open in de ingebouwde browser)
>
> Daarbij maak je ook netjes:
>
> - vermelding dat AI de module herschreven heeft
> - bron van de originele module + link (of fork maken, ook prima)
> - een tabel met de verwijzing per websocket intergratie punt die je gewijzigd hebt, welke wijziging je hebt aangebracht en motivatie waarom / wat er volgens jou niet klopte
